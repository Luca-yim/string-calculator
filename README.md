# String Calculator

> A TDD implementation of Roy Osherove's famous String Calculator Kata.
> Requirements revealed progressively — see [CHANGELOG](CHANGELOG.md) for the journey.

## Status

🚧 In progress. This project is a deliberate exercise in feeling the TDD
rhythm under evolving requirements.

## Usage (evolving)

\`\`\`javascript
const Calculator = require('./src/calculator');
const c = new Calculator();
c.add("1,2,3"); // 6
